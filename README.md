🎮 Echoes of Tomorrow



About the Game



Echoes of Tomorrow is a 2D platformer game developed using Unity and C#. The game features a player who explores a platform environment, collects fruits, avoids obstacles, and faces enemies.



✨ Features



\- Player movement (Left and Right)

\- Jumping system

\- Fruit collection system

\- Score counting system

\- 5 different fruits to collect

\- 5 obstacles in the game

\- Random enemy movement between obstacles

\- Game Over screen when the player collides with an enemy

\- Background environment



🛠️ Technologies Used



\- Unity Game Engine

\- C#

\- Visual Studio / VS Code

\- Pixel Adventure 1 Assets

\- TextMeshPro

\- Unity 2D Physics



🎯 Game Objective



The objective is to control the player, collect fruits, avoid obstacles, and stay safe from enemies.



🎮 Controls



Key| Action

A / Left Arrow| Move Left

D / Right Arrow| Move Right

Space| Jump
